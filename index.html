Speak a set

Say it in this order: set type, pass [level], quality [level], outcome. Say "pass" for the pass grade and either "quality" or "the set" for the set grade — the value word can come before or after ("pass perfect" or "perfect pass" both work).
Example: "Four ball, pass perfect, quality perfect, kill" — or just "Four ball, pass was better, set was clean, kill"
Pass/Quality words: bad/poor/rough/one = 1, playable/ok/decent/two = 2, perfect/good/better/solid/clean/three = 3 (quality also takes zero/unplayable) — say "not" before any of these to flip it
Outcome words: kill, error, in play, no attack
Mic stays on and keeps logging sets — one set is auto-added the moment all 4 fields are heard, then it listens for the next one. Click the button again to stop.
Mic idle. Click "Speak a set" and talk after it says Listening.

Log a set

Add one set at a time. Fields save as you build your history.

Bulk import

Paste stats you already have written down (e.g. from reviewing Balltime clips). One set per line.
Simplified format — one line per set, comma or tab separated (no Zone column — it's figured out from the set type):
SetType, PassLevel, Quality, Outcome, Notes

SetType: Middle: 1, 2, back1, push1, 31, bic · Left: shoot, 4, 32 · Right: 3, 5, c — anything else is filed as "Other"
PassLevel: 1/bad, 2/playable, 3/perfect — how good the pass you set off of was
Quality: 0-3 — how good your set was
Outcome: kill/k, error/e, inplay/ip, noattack/na

Example:
4, 3, 3, kill, clean swing
back1, 1, 2, inplay, bad pass, still ran it
Full format — one line per set, comma or tab separated (no Zone column — it's figured out from the set type):
Date, Opponent, SetType, PassLevel, Quality, Outcome, Notes

Example:
2026-08-10, Eastside, 4, 3, 3, kill, clean swing
2026-08-10, Eastside, back1, 1, 2, inplay, bad pass, still ran it

Diagnose your sets

Drag the setter along the net (2D), or walk them around the court yourself (3D — arrow keys / WASD once you click the court). Tap a set type below to send them there and see the target. The arc is colored by that type's real average quality — gray/dashed means you haven't logged any yet. The panel underneath breaks down what's actually happening with your numbers.
Click the court, then use arrow keys or WASD: left/right moves along the net, up/down steps toward or away from it. The orange line on the floor is the 10-foot attack line — bic and C ball are back-row attacks, so a legal hit on either has to take off from behind it.
